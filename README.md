# BARNES Office Contact

Адаптивный контактный блок BARNES Moscow с адресом офиса, email, мессенджерами и телефоном.

## Состав

- `index.html` — разметка блока;
- `styles.css` — desktop/mobile стили;
- `assets/` — фото офиса и локальные SVG-иконки.

Откройте `index.html` в браузере, чтобы посмотреть блок локально.
